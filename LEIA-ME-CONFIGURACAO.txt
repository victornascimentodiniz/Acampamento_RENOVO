3) LOGIN DO ADMINISTRADOR
Este código usa Supabase Auth de verdade.

No Supabase:
Autenticação -> Usuários

Crie ou confirme um usuário com:
- seu e-mail
- a senha que você escolher (pode ser "terrao" se o Supabase aceitar)

Depois o user_id desse usuário precisa existir na tabela:
public.administradores

Para conferir no SQL Editor:

select
    u.id,
    u.email,
    a.user_id is not null as eh_admin
from auth.users u
left join public.administradores a
    on a.user_id = u.id;

Se aparecer eh_admin = false, rode:

insert into public.administradores (user_id)
select id
from auth.users
where email = 'COLOQUE_AQUI_O_EMAIL_DO_ADMIN'
on conflict (user_id) do nothing;
